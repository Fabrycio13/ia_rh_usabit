### Technical decisions
- Sized the secondary brand text `people` at 30px, resulting in an x-height of ~16px. This is slightly smaller than the 22px x-height of `usabit`, creating a clear and standard visual hierarchy.
- Wrapped the original `usabit` paths in a `<g transform="translate(0, 4)">` tag to shift them down by 4px, giving 6px of baseline clearance at the bottom of the 40px viewBox so that the descenders of `p` in `people` render without clipping.
- Kept the font rendering dynamic in SVG via CSS fonts ('Inter', 'Montserrat', 'Poppins', sans-serif) to ensure optimal vector quality in browsers.
- Created the dark variant `#0f172a` (slate-900) for the `usabit` letters specifically for light mode interfaces, matching the card's text hierarchy and preventing low contrast on white backgrounds.
- Used SVG directly in React pages for crystal-clear vector scale, while generating equivalent PNG backups for compatibility.
