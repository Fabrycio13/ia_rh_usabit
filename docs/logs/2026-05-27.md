# Log de Atividades - 2026-05-27

## Fix: Envio de e-mails ao fechar vaga (`computeCloseEmailBreakdown`)

**Arquivo:** `src/pages/vagas/Vagas.tsx`

### Problemas corrigidos

#### Bug 1 — Candidaturas legadas ignoradas
A query filtrava por `organization_id`, o que excluía candidaturas criadas antes da migration 049 (sem `org_id`). Corrigido removendo o filtro desnecessário — o `vaga_id` já é suficiente para isolar os dados.

#### Bug 2 — Pipeline errado sendo puxado
A busca do pipeline usava `.maybeSingle()` sem filtrar por `is_active: true`, podendo retornar um pipeline inativo ou incorreto. Corrigido para:
1. Primeiro buscar o pipeline **ativo** (`is_active = true`)
2. Fallback: se não houver ativo, pega o mais recente da vaga

#### Bug 3 — Categorização incorreta de candidatos
A lógica anterior só colocava candidatos como `rejected` se eles **estivessem no pipeline E em coluna diferente de "Aprovado"**. Candidatos que nunca foram ao banco de talentos caíam em `others`.

Nova lógica:
- **Não foi ao banco de talentos** → `rejected` (e-mail de reprovação)
- **Foi ao banco + coluna "Aprovado" no kanban** → `approved` (e-mail de parabéns)
- **Foi ao banco + sem kanban ou outra coluna** → `others` (e-mail de agradecimento)

### UI melhorada
Labels do modal de preview de e-mails atualizadas para serem mais descritivas e refletir a nova lógica de negócio.
